# UI Reference

게임 UI 레퍼런스를 이름으로 검색하고, 플랫폼·장르별로 찾아보는 정적 웹사이트입니다.

## 기능
- 94개 게임, 11,158개 이미지·영상
- 플랫폼·장르 복수 필터, 한글·원문 게임명 검색
- 출시일·이름 오름차순 및 내림차순 정렬
- 이미지 확대, 영상, 즐겨찾기, 브라우저별 메타데이터 수정 및 백업

## 실행 및 배포
`index.html`을 브라우저로 열거나 정적 웹 서버로 제공합니다.
GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시 소스로 사용합니다.
빌드 도구나 외부 API, 외부 폰트가 필요하지 않습니다.

## 자료 기준
이미지는 긴 변 최대 2,048px WebP, 썸네일은 최대 480×360으로 제공합니다.
영상과 애니메이션은 원본 형식을 유지합니다. 로컬 원본 아카이브는 별도로 보관합니다.
장르·연도는 원본 수집 자료를 바탕으로 하며, 출처를 확인한 16개 게임의 플랫폼·출시일을 보완했습니다.
나머지는 플랫폼 미확인과 원본 연도로 구분합니다. 출시일 정렬은 확인된 날짜를 먼저 표시합니다.
각 게임의 정보 출처와 기준 지역을 상세 화면에서 확인할 수 있습니다.

## 저장 방식
즐겨찾기와 정보 수정은 방문자 각자의 브라우저에만 저장됩니다.
서버나 저장소의 공용 데이터를 변경하지 않습니다.

게임 이미지·영상의 권리는 각 제작사에 있습니다. 이 사이트는 공식 서비스가 아닌 UI 연구용 아카이브입니다.
